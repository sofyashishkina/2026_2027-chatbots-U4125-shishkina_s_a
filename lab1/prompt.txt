Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot.

Бот предназначен для творческой мастерской You Art в Санкт-Петербурге.

Основная задача бота:
1. Сохранять аудиторию, которая уже знакома с мастерской.
2. Отправлять всем пользователям общую рассылку с новостями You Art, тематическими мастер-классами, новыми направлениями и афишей.
3. Давать клиентам быстрый доступ к каталогу мастер-классов, прайсу, афише, условиям бронирования, информации о праздниках, подарочных сертификатах и записи.

Все пользователи, которые запустили бота через /start, автоматически считаются подписчиками новостей You Art.

Отдельной кнопки «Подписаться» и сегментации аудитории не нужно.

Рассылка единая для всех пользователей бота.

Функционал бота:
- приветствие пользователя;
- главное меню с кнопками;
- каталог мастер-классов в виде фотокарточек;
- прайс в виде двух готовых изображений;
- афиша групповых мастер-классов;
- информация о праздниках в You Art;
- отдельный раздел для записи;
- условия бронирования;
- подарочные сертификаты;
- контакты и адрес мастерской;
- административная команда для общей рассылки всем пользователям;
- хранение пользователей в SQLite;
- автоматическая обработка заблокировавших бота пользователей.

--------------------------------------------------

--------------------------------------------------

Бот должен:

2. Если пользователь уже существует — не создавать дубликат, а обновить дату последней активности.
3. Считать пользователя активным подписчиком общей рассылки.
4. Отправить приветственное сообщение.
5. Показать главное меню.

ВАЖНО:

В Telegram нельзя отправить более 10 изображений в одном MediaGroup.

Поэтому бот должен:

1. Получить все изображения из папки assets/catalog/.
2. Отсортировать их по имени.
3. Автоматически разделить изображения на группы максимум по 10 файлов.
4. Отправить все группы последовательно.
5. Не требовать от пользователя нажимать кнопку «Далее».
6. Сохранять правильный порядок карточек.

Например:

1 группа:
01.jpg–10.jpg

2 группа:
11.jpg–20.jpg

3 группа:
21.jpg и далее.

Количество карточек НЕ должно быть жёстко прописано в коде.

Если в будущем в папку будет добавлена карточка 23.jpg, бот должен автоматически включить её в каталог без изменения программного кода.

Если одна фотография повреждена или отсутствует, бот не должен полностью завершаться с ошибкой.

--------------------------------------------------
ОБЩАЯ РАССЫЛКА
--------------------------------------------------

Все пользователи, которые хотя бы один раз запустили бота через /start, считаются подписчиками новостей.

Отдельной кнопки «Подписаться» не создавать.

Отдельной сегментации пользователей не создавать.

Все новости отправляются одной общей базе.

Администратор должен иметь возможность создать рассылку через команду:

/broadcast

Команда доступна ТОЛЬКО администратору.

Telegram ID администратора хранить в .env:

ADMIN_ID=

Логика /broadcast:

1. Администратор пишет:
/broadcast

2. Бот отвечает:

«Отправьте сообщение, которое хотите отправить всем пользователям.»

3. Администратор может отправить:
- обычный текст;
- фотографию с подписью;
- видео с подписью.

4. Бот должен сохранить сообщение временно и показать администратору предварительный просмотр.

5. После предварительного просмотра показать кнопки:

«✅ Отправить всем»
«❌ Отмена»

6. При нажатии «Отправить всем» сообщение отправляется всем активным пользователям из SQLite.

7. Ошибка при отправке одному пользователю НЕ должна останавливать всю рассылку.

8. После завершения бот сообщает администратору:

«Рассылка завершена.

Всего пользователей: N
Успешно отправлено: N
Не удалось отправить: N»

9. Если Telegram сообщает, что пользователь заблокировал бота или бот больше не может отправлять ему сообщения, установить:

is_active = 0

и сохранить время блокировки.

В следующих рассылках таким пользователям сообщения не отправлять.

- При первом запуске автоматически создавать SQLite-файл и необходимые таблицы.
- Не допускать дублирования пользователей.
- Проверять ADMIN_ID перед выполнением /broadcast.
- Обычный пользователь не должен иметь доступ к административным функциям.
- Ошибка рассылки одному человеку не должна останавливать рассылку остальным.
- Корректно обрабатывать Telegram Forbidden / BadRequest / NetworkError и другие типичные ошибки.
- Добавить глобальный обработчик ошибок.
- Добавить graceful shutdown.
- Код должен быть структурирован по функциям, а не находиться целиком внутри одного большого обработчика.
- Все тексты интерфейса вынести в отдельные константы в верхней части bot.py или в отдельную логически организованную структуру.
- Не размазывать одинаковые контакты и ссылки по всему коду.
- Все изменяемые контакты получать из .env.
- Бот должен корректно работать после перезапуска и сохранять базу пользователей.
- Использовать HTML или MarkdownV2 для форматирования сообщений, но обязательно корректно экранировать пользовательские данные.
- Все InlineKeyboardButton должны иметь понятную логику.
- После нажатия callback-кнопок корректно вызывать answer(), чтобы Telegram не показывал бесконечную загрузку.
