# Описание

В этой лабораторной работе будет создан Telegram-бот, с использованием только естественного язык и LLM.

# Цель работы

Научиться создавать работающего бота для решения реальных бизнес-задач, используя AI-инструменты вместо написания кода вручную.

# Ход работы

## Шаг 1: Выбор задачи

Предложен свой вариант бота:

### Telegram-бот для творческой мастерской [You Art](https://vk.ru/ya.workshop)
- Показывает каталог мастер-классов с фотографиями
- Предоставляет актуальный прайс и афишу мероприятий
- Рассказывает об организации праздников и подарочных сертификатах
- Информирует об условиях бронирования и записи
- Предоставляет контакты, адрес и ссылки на социальные сети
- Позволяет клиентам быстро связаться с администратором
- Обеспечивает удобную навигацию по разделам через кнопки

## Шаг 2: Создание бота в Telegram

Создан бот с username: `itmoftmi_SA_bot`. Токен сохранён в безопасном месте.

## Шаг 3: Составление промпта для LLM

ChatGPT, который хорошо знаком с контекстом мастерской, предложено описать подробные требования к боту и сформулировать их в качестве промта, который и будет использован для генерации кода.

Фрагмент полученного промпта:

```
Бот предназначен для творческой мастерской You Art в Санкт-Петербурге.

Основная задача бота:
1. Сохранять аудиторию, которая уже знакома с мастерской.
2. Отправлять всем пользователям общую рассылку с новостями You Art, тематическими мастер-классами, новыми направлениями и афишей.
3. Давать клиентам быстрый доступ к каталогу мастер-классов, прайсу, афише, условиям бронирования, информации о праздниках, подарочных сертификатах и записи.

Все пользователи, которые запустили бота через /start, автоматически считаются подписчиками новостей You Art.

Отдельной кнопки «Подписаться» и сегментации аудитории не нужно.

Рассылка единая для всех пользователей бота.

Функционал бота:
- приветствие пользователя;
- главное меню с кнопками;
- каталог мастер-классов в виде фотокарточек;
- прайс в виде двух готовых изображений;
- афиша групповых мастер-классов;
- информация о праздниках в You Art;
- отдельный раздел для записи;
- условия бронирования;
- подарочные сертификаты;
- контакты и адрес мастерской;
- административная команда для общей рассылки всем пользователям;
- хранение пользователей в SQLite;
- автоматическая обработка заблокировавших бота пользователей.

...
```

Полный текст промпта находится в файле `prompt.txt`.


## Шаг 4: Генерация кода

LLM дана команда разработать бота, описанного в `prompt.txt`.

Далее создан и заполнен недостающими данными файл `.env` (токен бота, ID админа, ссылки на соцсети).

Также заполнена папка с ассетами `assets`: 
- `catalog` - папка с карточками мастер классов;
- `event` - папка с карточками афиши;
- `price` - папка с прайс листами (оставлена пустой).
