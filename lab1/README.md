# Telegram-бот You Art

Бот творческой мастерской You Art показывает каталог мастер-классов, прайс и афишу, рассказывает о праздниках, записи, бронировании и сертификатах, а также предоставляет контакты мастерской. Пользователь выбирает разделы кнопками и может вернуться в главное меню из каждого раздела.

Каждый пользователь, отправивший `/start` в личном чате бота, становится подписчиком общей рассылки. Пользователи сохраняются в SQLite и остаются в базе после перезапуска. Отдельной подписки и сегментации нет.

## 1. Установите Python

Нужен **Python 3.10 или новее**. Скачайте установщик с [python.org](https://www.python.org/downloads/). При установке в Windows включите добавление Python в `PATH`.

Проверьте установку в терминале:

```powershell
python --version
```

В Windows можно использовать `py` вместо `python`, если команда `python` недоступна.

## 2. Создайте виртуальное окружение

Откройте терминал в папке `lab1`. Все следующие команды выполняются из неё, если не указано иначе.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает активацию, используйте Python окружения напрямую; менять настройки безопасности не требуется:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Linux и macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Установите зависимости

После активации окружения:

```powershell
python -m pip install -r requirements.txt
```

Используются `python-telegram-bot` для асинхронного Telegram API, `python-dotenv` для настройки через `.env` и Pillow для проверки изображений. SQLite входит в стандартную библиотеку Python.

## 4. Создайте бота через BotFather

Откройте в Telegram официальный аккаунт [@BotFather](https://t.me/BotFather), отправьте `/newbot` и задайте имя и уникальный username бота по его подсказкам. Username обычно заканчивается на `bot`.

Если бот уже создан, используйте его существующий токен: создавать второго бота не нужно.

## 5. Получите BOT_TOKEN

После `/newbot` BotFather выдаст токен доступа. Токен существующего бота можно получить через `/mybots` → выбрать бота → `API Token`.

Скопируйте токен в `BOT_TOKEN` файла `.env`. Токен даёт доступ к управлению ботом: не публикуйте его и не добавляйте в Git. Если токен раскрыт, замените его через BotFather.

## 6. Узнайте Telegram ID администратора

Напишите [@userinfobot](https://t.me/userinfobot) со своего аккаунта и возьмите значение `Id`. Это **числовой ID личного аккаунта**, а не username, номер телефона или ID бота.

Укажите его в `ADMIN_ID`. Значение должно быть целым числом больше нуля; `0` не подходит. После успешного запуска команда `/id` также показывает ID отправителя.

## 7. Создайте и настройте .env

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Linux и macOS:

```bash
cp .env.example .env
```

Откройте `.env` и заполните настройки:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Обязательный токен от BotFather. |
| `ADMIN_ID` | Обязательный положительный числовой ID администратора. |
| `BOOKING_CONTACT` | Обязательный контакт, отображаемый в сообщениях, например `@sofaa_sh`. |
| `BOOKING_URL` | Обязательная ссылка кнопок записи, например `https://t.me/sofaa_sh`. |
| `PHONE` | Обязательный телефон мастерской, например `+79133105561`. |
| `VK_URL` | Необязательная ссылка на сообщество ВКонтакте. |
| `TELEGRAM_URL` | Необязательная ссылка на Telegram мастерской. |
| `MAP_URL` | Необязательная ссылка на карту или маршрут. |

В примере уже указаны контакты из задания и страница ВКонтакте из отчёта. Ссылки Telegram мастерской и карты оставлены пустыми: заполните их настоящими адресами при необходимости. Кнопки необязательных ссылок с пустым значением скрываются.

Файл должен называться именно `.env`, без окончания `.txt`, и находиться рядом с `bot.py`. Настройки читаются при запуске: после изменения `.env` перезапустите бота. Если переменные заданы в окружении процесса, они имеют приоритет над `.env`.

## 8. Добавьте изображения каталога

Поместите готовые фотокарточки в `assets/catalog/`:

```text
assets/catalog/
    01.jpg
    02.jpg
    03.jpg
    ...
    21.jpg
    22.jpg
```

Поддерживаются `.jpg`, `.jpeg` и `.png`. Бот сортирует файлы по имени и отправляет все карточки последовательно, без кнопки «Далее». Используйте ведущие нули (`01`, `02`, …), а при сотне карточек — одинаковую ширину номера (`001`, `002`, …), чтобы порядок имён совпадал с нужным порядком просмотра.

Карточки должны содержать названия, цены и описания: отдельные описания бот не генерирует. Число карточек не ограничено кодом.

## 9. Добавьте два изображения прайса

Сохраните прайс с точными именами:

```text
assets/price/price_1.jpg
assets/price/price_2.jpg
```

Оба изображения отправляются одним альбомом в указанном порядке. Если хотя бы один файл отсутствует или повреждён, бот сообщит, что прайс обновляется, и предложит уточнить стоимость при записи. Цены текстом не дублируются.

## 10. Добавьте изображения афиши

Поместите актуальные карточки групповых мастер-классов в `assets/events/` с именами `01.jpg`, `02.jpg` и далее. Форматы и порядок такие же, как у каталога. Удаляйте карточки прошедших мероприятий самостоятельно: бот не определяет даты по изображению.

При пустой папке бот показывает сообщение об отсутствии открытых групповых мастер-классов.

### Требования к изображениям

Каждый файл фотографии должен быть не больше **10 МБ**; сумма ширины и высоты — не больше **10 000 пикселей**, отношение большей стороны к меньшей — не больше **20**. Подготовьте обычные статичные JPG или PNG подходящего размера. Бот проверяет изображения, пропускает повреждённые и неподходящие файлы и записывает причину в журнал.

Telegram принимает от 2 до 10 фотографий в одном альбоме (`MediaGroup`). Поэтому каталог и афиша автоматически разбиваются на группы по 10, а одиночный файл или последний остаток из одного изображения отправляется отдельной фотографией. Отсутствие папки или неисправность отдельного файла не останавливает приложение.

## 11. Запустите бота

Из папки `lab1` с активированным виртуальным окружением:

```powershell
python bot.py
```

Можно запустить из корня репозитория, используя Python, в котором установлены зависимости:

```powershell
python lab1/bot.py
```

Все пути к `.env`, изображениям, базе и журналу определяются относительно `bot.py`, поэтому рабочая папка терминала не меняет расположение данных. При первом запуске автоматически создаются `data/bot.db`, необходимые таблицы и `logs/bot.log`.

Откройте бота в Telegram и отправьте `/start`. Для работы нужен доступ к Telegram API через интернет. Запускайте только один процесс с одним токеном: бот получает обновления через polling.

Чтобы завершить работу, нажмите `Ctrl+C`. Бот корректно завершает обработку; если рассылка уже идёт, дождитесь её окончания. При следующем запуске база пользователей сохраняется.

### Команды

| Команда | Действие |
| --- | --- |
| `/start` | Регистрация или обновление пользователя и главное меню. |
| `/menu` | Главное меню. |
| `/catalog` | Каталог мастер-классов. |
| `/price` | Прайс. |
| `/events` | Афиша. |
| `/party` | Праздники в You Art. |
| `/booking` | Условия бронирования. |
| `/signup` | Контакт и кнопка записи. |
| `/certificates` | Подарочные сертификаты. |
| `/contacts` | Адрес, телефон и ссылки. |
| `/id` | Числовой Telegram ID отправителя. |
| `/broadcast` | Создание общей рассылки; только администратор в личном чате. |
| `/cancel` | Отмена подготовки рассылки. |

## 12. Отправьте общую рассылку

1. Откройте **личный чат** бота с аккаунта, указанного в `ADMIN_ID`.
2. Отправьте `/broadcast`.
3. Пришлите одно сообщение: текст, одну фотографию с подписью или одно видео с подписью. Альбомы и другие типы сообщений не поддерживаются.
4. Проверьте предварительный просмотр.
5. Нажмите «✅ Отправить всем» или «❌ Отмена». До подтверждения можно также отправить `/cancel`.

Рассылка идёт всем активным пользователям базы, которые отправляли `/start`, включая администратора, если он тоже зарегистрирован. Повторное нажатие подтверждения не запускает ту же рассылку заново. Во время текущей рассылки нельзя создать ещё одну. Итог содержит количество получателей, успешных отправок и ошибок.

Ошибка одного получателя не прерывает отправку остальным. Пользователи, заблокировавшие бота или ставшие постоянно недоступными для отправки, помечаются неактивными с датой блокировки и исключаются из следующих рассылок. После нового `/start` пользователь вновь активен.

Черновик хранится временно в памяти и удаляется при перезапуске. Рассылка не имеет постоянной очереди: после аварийного завершения процесса незавершённая отправка автоматически не продолжается. Повторный запуск рассылки вручную отправит сообщение также тем, кто мог уже его получить.

## 13. Замените прайс

Замените `assets/price/price_1.jpg` и `assets/price/price_2.jpg` новыми файлами с теми же именами. Подготовьте оба изображения заранее и заменяйте их между обращениями к разделу. При следующем открытии прайса бот прочитает новые файлы; изменения Python-кода и перезапуск не нужны.

## 14. Добавьте новую карточку мастер-класса

Скопируйте новую карточку в `assets/catalog/`, например `23.jpg`. При следующем открытии каталога она будет включена автоматически. Сохраняйте единый формат нумерации, чтобы новая карточка попала на нужное место. Перезапуск не требуется.

## 15. Измените контакт для записи

Измените `BOOKING_CONTACT` и `BOOKING_URL` в `.env`, затем перезапустите процесс. Например, при смене Telegram-аккаунта измените и отображаемый `@username`, и ссылку `https://t.me/username`. Эти же настройки используются в записи, сертификатах и контактах. Телефон меняется через `PHONE`.

## 16. Измените ссылки ВКонтакте, Telegram и карты

Укажите полные адреса в `VK_URL`, `TELEGRAM_URL` и `MAP_URL` файла `.env`, затем перезапустите бота. Чтобы скрыть ненужную кнопку, оставьте значение после `=` пустым. Для карты используйте готовую ссылку на расположение мастерской или маршрут из выбранного сервиса карт.

## 17. База пользователей и журнал

SQLite-база находится в `lab1/data/bot.db`. Таблица `users` содержит:

```text
id, telegram_id, username, first_name, last_name,
first_seen_at, last_seen_at, is_active, blocked_at
```

`telegram_id` уникален: повторный `/start` обновляет сведения и дату последней активности, активирует подписку, но не создаёт вторую запись. Даты хранятся в UTC.

Перед резервным копированием базы корректно остановите бота. Сохраните файл `data/bot.db` и верните его по тому же пути перед запуском, чтобы перенести аудиторию. Не удаляйте базу для обычного обновления программы.

Журнал ошибок и работы находится в `lab1/logs/bot.log`. Пользователь получает понятное сообщение об ошибке без технических деталей. `.env`, база, журнал и виртуальное окружение исключены из Git локальным `.gitignore`.

## Проверка проекта

После установки зависимостей из папки `lab1`:

```powershell
python -m unittest discover -s tests -v
```

Автоматические проверки используют временные файлы и имитацию Telegram API. Для окончательной проверки работы с Telegram заполните `.env`, запустите бота и пройдите меню, затем подтвердите тестовую рассылку с аккаунта администратора, учитывая, что она отправится всей активной базе.
